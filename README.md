# GhépXe Demo

Bản demo nhấp được của phần mềm quản lý nhà xe ghép (tổng đài, chủ hãng, tài xế, khách hàng, quản trị nền tảng). Dữ liệu trong demo là dữ liệu giả lập.

Trang chạy tại https://datxe.hcarevietnam.vn

`index.html` được dựng từ file nguồn `ghepxe-demo.html` (thêm phần đầu trang, biểu tượng và manifest để thêm vào màn hình chính).
